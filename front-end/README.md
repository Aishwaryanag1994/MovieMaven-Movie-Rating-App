# MovieMaven — Frontend

MovieMaven is a movie-rating application frontend built with React.

## Technologies

- React
- React Router
- Axios
- Ant Design
- Tailwind CSS

## Getting Started

1. Install Node.js and npm.
2. Open a terminal in the `front-end` directory.
3. Install dependencies:

   `npm install`

4. Start the development server:

   `npm start`

The frontend currently uses a local backend at `http://localhost:4000`.

## Project Structure

- `public/` — public assets
- `src/` — React application source code
- `package.json` — dependencies and scripts
